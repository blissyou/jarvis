# PRD
#voice-ai #agent #architecture #mvp #security #automation

## 목적
JARVIS 프로젝트의 제품 요구사항을 명확히 정의하여 설계, 구현, 테스트, 릴리즈의 기준 문서로 사용한다.

## 핵심 요약
- JARVIS는 음성 명령을 이해하고, 승인된 범위 안에서 실제 도구를 실행하는 개인 AI 비서다.
- MVP는 `음성 입력`, `기술 뉴스 스크럼`, `주식 브리핑`, `이메일 초안 작성 + 승인 후 발송`, `음성 응답`에 집중한다.
- 핵심 성공 조건은 “똑똑해 보이는 대화”가 아니라 “실수 없이 안전하게 실행되는 승인형 경험”이다.

## 상세 내용
### 제품 개요
JARVIS는 브라우저 기반 음성 AI 비서다. 사용자는 마이크로 요청을 말하고, 시스템은 STT/LLM/TTS 및 외부 API를 이용해 요청을 이해하고 결과를 반환한다. 읽기 작업은 빠르게 실행하고, 쓰기 작업은 승인 단계를 거친다. MVP에서는 정보 제공과 제한적 생산성 자동화에 집중한다.

### 사용자 문제
- 매일 여러 출처에서 기술 뉴스를 직접 모으는 것이 번거롭다.
- 주식 정보를 확인할 때 시세와 뉴스가 분리되어 있어 맥락 파악이 어렵다.
- 이메일 작성은 반복적이지만 자동 발송은 위험하다.
- 음성 인터페이스는 편리하지만 실제 실행까지 이어지는 제품은 드물다.
- 기존 챗봇은 정보를 말해줄 뿐, 승인형 실행 구조가 부족하다.

### 핵심 사용자
#### 1. 개인 개발자
- 기술 뉴스 스크럼을 빠르게 받고 싶다.
- GitHub, 문서, 개발 맥락과 연결된 개인 비서를 원한다.

#### 2. 정보 중심 투자 사용자
- 특정 종목의 현재가, 변동률, 뉴스만 빠르게 듣고 싶다.
- 투자 판단이 아니라 정보 브리핑이 필요하다.

#### 3. 생산성 중시 직장인
- 이메일 초안을 음성으로 만들고 싶다.
- 자동 발송이 아니라 승인 기반 발송을 원한다.

### MVP 기능
- 음성 입력
- 기술 뉴스 요약
- 주식 조회
- 이메일 초안 작성
- 사용자 승인 후 이메일 발송
- 음성 응답
- 세션별 작업 흐름 시각화
- tool 호출, 승인, 실행 결과를 한 화면에서 추적 가능한 workflow view
- Mermaid 또는 UI 기반 workflow view 제공
- Settings UI를 통한 사용자 API 키 저장/검증/삭제
- 실행 로그 저장
- 승인 로그 저장

### 비포함 기능
- 일정 자동 등록
- 리마인더 자동 발송
- GitHub 쓰기 작업
- 파일 수정/삭제
- 터미널 실행
- IoT 제어
- 장기 메모리 기반 적극적 개인화
- 모바일/데스크톱 앱 동시 지원

### 성공 기준
| 항목 | 기준 |
|---|---|
| 음성 응답 지연 | 사용자 체감상 실용적일 것 |
| 이메일 안전성 | 발송 전 100% 승인 필수 |
| 뉴스 품질 | 핵심만 한국어 요약, 출처 링크 포함 |
| 주식 응답 | 현재가/변동/관련 뉴스 포함 |
| 실행 추적성 | 모든 tool 호출과 승인 이벤트 기록 |
| Workflow 추적성 | 세션별 작업 상태와 흐름을 시각화 가능 |
| Secret 보안성 | API 키는 암호화 저장, 마스킹 표시, 삭제 가능 |
| 사용자 경험 | 한 화면에서 transcript, 결과, 승인 흐름 확인 가능 |

### 위험 요소
| 위험 | 설명 | 대응 |
|---|---|---|
| STT 오인식 | 잘못된 수신자, 종목명 인식 오류 | 후속 질문, 승인 단계 |
| 모델 환각 | 잘못된 tool 선택 또는 설명 | schema 검증, 승인 정책 |
| 오발송 | 이메일이 잘못 전송될 수 있음 | draft 우선, 최종 승인 |
| 외부 API 품질 | 뉴스/주식 데이터 지연 또는 누락 | fallback, 오류 메시지 |
| 범위 과확장 | 너무 많은 기능을 초기에 포함 | MVP 통제 |
| 작업 흐름 로그 누락 | 실제 실행은 됐지만 시각화 복원이 불완전할 수 있음 | workflow_events 별도 저장 |
| 상태 불일치 | 실제 tool 상태와 시각화 상태가 다를 수 있음 | 단일 상태 원천과 검증 로직 유지 |

### 릴리즈 기준
#### Alpha
- 로컬 환경에서 음성 뉴스/주식/이메일 초안 생성 성공
- 최소 로그 저장

#### Beta
- 승인 UI 포함
- Gmail 발송 승인 흐름 안정화
- 에러 처리와 재시도 추가

#### MVP Release
- README, API, DB, Prompt 문서 정리 완료
- 핵심 기능 5개 안정 동작
- 모니터링 및 감사 로그 확보
